# Mi Universo

Una página web personal para practicar Git y GitHub.

## Cómo abrirla

Abre `index.html` en tu navegador. No necesitas instalar nada.

## Archivos

- `index.html`: contenido de la página.
- `styles.css`: diseño, colores y adaptación a móvil.
- `script.js`: botón de retos y cambio de tema.

## Retos para futuros commits

1. Cambia el título principal en `index.html`.
2. Cambia `--accent` en `styles.css`.
3. Agrega un reto al arreglo `retos` en `script.js`.
4. Agrega tu quinto gusto o afición.

**Git no está inicializado en esta carpeta:** practica tú mismo `git init`, `git add`, `git commit` y `git push`.
